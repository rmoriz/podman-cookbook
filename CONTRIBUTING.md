# Contributing

Please refer to
[https://github.com/chef-cookbooks/community_cookbook_documentation/blob/main/CONTRIBUTING.MD](https://github.com/chef-cookbooks/community_cookbook_documentation/blob/main/CONTRIBUTING.MD)

Run `chef exec rspec` and `cookstyle` before opening a pull request. Every
resource needs a documentation page, a ChefSpec example, a test recipe, a
Kitchen suite and InSpec controls.
